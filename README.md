# 🏚️ Rent Trap Index
### City Affordability Intelligence for Indian Professionals

## Problem Statement
A fresher accepting a ₹6 LPA offer in Mumbai vs Bhubaneswar
isn't making the same financial decision — they're living
completely different financial lives. This dashboard quantifies that.

## What It Does
- Calculates Rent Trap % for 12 major Indian cities
- Shows Comfort Score — how much salary is truly yours after expenses
- Interactive What-If calculator — enter your expected salary and see which city suits you best
- Ranks cities from most to least liveable for freshers

## Dataset & Sources
- Salary data: AmbitionBox / Glassdoor
- Rent data: NoBroker / MagicBricks
- Cost of living: Numbeo
- Cities covered: Bengaluru, Mumbai, Delhi, Hyderabad, Chennai, Pune,
  Kolkata, Ahmedabad, Jaipur, Kochi, Bhubaneswar, Indore

## Key DAX Measures
- Rent Trap % = Rent / Salary * 100
- Comfort Score = Salary - Total Monthly Expenses
- Break Even Months = 1,00,000 / Monthly Savings
- Affordability Rank = RANKX by Rent Trap %
